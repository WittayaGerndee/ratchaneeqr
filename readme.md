5. การทำงานของ LINE OA

มี 2 แนวทาง

แบบ A — QR Code เปิด LINE OA

QR ของนักเรียนอาจเป็น URL ที่เปิด LINE OA พร้อม Parameter เช่น

https://line.me/R/oaMessage/@school/?student=65001

เมื่อเปิด ระบบสามารถนำรหัสนักเรียนไปประมวลผลต่อ

แต่ผมแนะนำให้ระวังเรื่องการแก้ไข URL/Parameter
